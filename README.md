## 价格是怎么涨到40美元的？

Premium+这两年的价格轨迹大致如下：

- 2024年12月21日前：每月16美元，年费168美元
- 2024年12月21日起：每月22美元，年费229美元，涨幅约40%。当时Mashable的报道提到，新订阅者当天生效，老用户从次年1月20日之后的续费周期开始按新价扣款，官方没有提供任何老价格保护；部分市场涨幅更狠，Mashable援引TechCrunch的统计，尼日利亚从不足5美元直接跳到22美元
- 2025年2月18日起：每月40美元，年费395美元。老用户如果在3月22日前开始下一个扣费周期，还能按原价扣一次，之后的周期执行新价

两次调价间隔不到两个月，累计涨了150%。

至于为什么涨，官方在调价公告里给了三个理由：一是Premium+用户能以更高的用量上限使用Grok 3，并提前体验新功能；二是完全无广告的体验；三是订阅收入会注入创作者激励计划，按内容质量和互动分配收益，而不再看广告展示量。

第三方的解读要直白一些。Mashable指出，自马斯克2022年底收购Twitter以来，X的广告收入明显下滑，大广告主陆续撤离，平台因此转向更依赖订阅用户的收入结构。官方自己在公告里也留了一句：“提高价格，是为了持续投入把Premium+做得更好。”

## Premium+贵在哪：三档功能差在哪

三档的分工其实挺清楚：Basic解决发帖体验，Premium解决身份和广告，Premium+解决“全都要”。

**Basic（$3/月）**：编辑已发布的帖子（限发帖后1小时内）、最长25,000字符的长文、更长时间的视频上传（官方标称最高约3小时、8GB、1080p）、回复区置顶权重、文本格式、书签文件夹、自定义App图标。注意，Basic不含蓝V认证。

**Premium+（$40/月）**：Premium的全部功能，再叠加：

- 全站无广告：覆盖推荐流、关注流、回复区、个人主页等大部分区域；条款同时写明，偶尔可能出现推广内容

- Articles长文发布、Radar搜索

- X Pro多时间线管理工具

蓝V这里有个容易踩的坑：它只随Premium和Premium+发放，审核可能需要几个工作日；期间如果改了头像、昵称或用户名，蓝V会暂时消失，等重新审核通过才回来。打算在大动作前改名的，建议把时间差算进去。
